## AI Credits / Token Vendor Sponsorship

Nuva OS development, hardware integration, version testing, and public demonstrations continuously consume model tokens. Model vendors, API platforms, aggregation platforms, or proxy services are welcome to provide API credits, token packages, trial accounts, or developer-specific quotas.

Sponsored credits will be prioritized for:

- Continuous development of the AI-native quantum-safe open-source OS Nuva OS
- Quantum-safe hardware integration and optimization
- Hardware system testing and version verification
- SDK, demo, documentation, and public demonstration model consumption
- AI-native OS performance optimization and scaling
- AI-native OS security hardening and vulnerability fixes
- Nuva language enhancement and extension
- Public Nuva OS development tutorial guides
- Issue reproduction and open-source maintenance

Available collaboration formats:
